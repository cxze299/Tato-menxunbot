# 门训同行 Potato Bot

这是 [Disciple-deltachat-bot](https://github.com/cxze299/Disciple-deltachat-bot) 的 Potato 适配版。项目直接复用参考仓库的完整业务代码，只替换聊天收发层，因此网站同步、状态判断、提醒和管理员规则保持一致。

## 用户第一次使用

请私聊机器人，严格按下面顺序发送：

```text
网站
科大
绑定 你的真实姓名
打卡 灵修
```

说明：

- 当前可选网站：科大、Agape、浙外特教、Longway、浙外万向。
- 也可以发送 `切换 网站名称`，例如 `切换 科大`。
- 姓名必须与门训网站成员名单完全一致，例如网站写的是“张三”，就不能输入昵称。
- 所有指令都必须私聊机器人完成。群聊只接收通知，机器人会静默忽略群内的任何文字和指令（包括“帮助”）。

## 用户指令

机器人使用中文指令，不需要 `/`：

```text
网站
切换 科大
绑定 姓名

灵修
任务
打卡 灵修
打卡 周读物
打卡 视频
打卡 背经
补签 视频 昨天
补签 灵修 2026-08-20
取消打卡 灵修
取消打卡 视频 2026-08-20

我的状态
我的月状态
我的月状态 2026-08
门训总结
群状态
本周总结
历史总结
提醒 对方姓名
帮助
```

所有用户都可以在私聊中发送 `本周总结` 或 `历史总结`，查看全组总体，以及灵修、周读物、视频、背经四个打卡按钮各自的完成分析和每位成员明细。全组历史总结统一从 `2026-04-06` 开始统计；`门训总结` 仍用于查看自己个人的历史统计。

## 管理员指令

先在服务器运行 `python set_admin_key.py`，然后管理员私聊机器人：

```text
管理员验证 你的密钥
管理员状态
管理员 网站状态
管理员 成员列表
管理员 群列表
管理员 绑定群
管理员 解绑群
管理员 设置加入日期 科大 姓名 2026-01-01
管理员 广播 公告内容
管理员 发布灵修
管理员 立即提醒 早间
管理员 立即提醒 晚间
管理员 本周总结
管理员 历史总结
管理员解除
```

其中 `管理员 本周总结` 和 `管理员 历史总结` 会把全组总体统计及每位成员明细发送到当前网站配置的通知群；命令本身只能在私聊中执行。

`管理员 群列表` 会显示机器人已发现的群 ID、群名称、群类型和绑定状态。新群若尚未出现，请先把机器人加入群，并在群里发送任意一条消息。超级管理员私聊发送 `管理员 绑定群`，按编号选群；机器人会根据群名推荐 Cedar 小组，回复“确认”才绑定，也可以选“其他”手动选择 Cedar 小组。发送 `管理员 解绑群` 可按提示选择已绑定的 Cedar 群并确认解绑。此入口不提供旧网站的新群绑定。

## 配置

复制 `config.example.json` 为 `config.json`，填写 Bot token。科大网站配置必须保持：

```json
{
  "id": "zk",
  "name": "科大",
  "url": "https://mouss.synology.me:1777/",
  "chat_ids": [],
  "timezone": "Asia/Shanghai",
  "devotion_time": "06:00",
  "morning_time": "08:30",
  "evening_time": "20:30",
  "enabled": true
}
```

## Windows 启动

```powershell
cd D:\Potato\mentorship_bot
python bot.py
```

## NAS 部署

参见 [NAS部署.md](NAS部署.md)。核心命令：

```sh
chmod +x manage.sh
./manage.sh setup
./manage.sh admin-key
./manage.sh start
./manage.sh logs
```

同一个 Bot token 只能运行一个轮询实例。NAS 启动后请停止 Windows 实例。

## 数据与安全

- `config.json`：Bot token 和网站配置，不提交 Git。
- `data/state.json`：用户绑定、管理员、提醒和网站监听状态。
- `data/admin-key.json`：管理员密钥的 PBKDF2 哈希，不保存明文。
- Potato API：`getUpdates` 接收消息，`sendTextMessage` 发送消息。
